
# Presensi Mimici

Sistem presensi karyawan untuk enam cabang Mimici.

## Teknologi

- Frontend: React.js + Vite
- Backend: Node.js + Express.js
- Database: PostgreSQL

## Struktur Proyek

- `client/`: aplikasi frontend
- `server/`: REST API backend
- `database/`: migrasi dan data awal database
- `docs/`: dokumentasi proyek

## Menjalankan Frontend

```bash
cd client
npm install
npm run dev
```

## Menjalankan Backend

```bash
cd server
npm install
npm run dev
```

Konfigurasikan variabel lingkungan backend sebelum menghubungkan database.
